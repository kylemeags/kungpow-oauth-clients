# kungpow-oauth-clients

Public OAuth **Client ID Metadata Documents** for Kung Pow Marketing's internal tools
(draft-ietf-oauth-client-id-metadata-document). These files contain no secrets: a client_id
of this kind is simply the HTTPS URL of the document, and the clients are public PKCE clients.

| File | Used by |
|---|---|
| `upwork-monitor.json` | Great Fit Job Monitor → Upwork MCP (`mcp.upwork.com`) |
